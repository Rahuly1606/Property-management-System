DEVELOPMENT SETUP
1. npm install
2. Create .env.development with VITE_API_URL=http://localhost:8082
3. npm run dev (http://localhost:5173)
Build: npm run build (output: dist/)
Docker: docker build -t pms-frontend . && docker run -p 80:80 pms-frontend
